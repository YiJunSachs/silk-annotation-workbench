# Silk 标注工作台

本地运行的帛书矩形标注编辑器，包含 27 张待复核图片、13,970 个原始标注框，以及独立的残卷讨论页（78 张：27 张重点残卷、33 张残损可用候选、16 张历史已剔除图片、2 张保留对照）。原数据集不在本项目的写入范围内。

## 启动

需要 Python 3.9 或更高版本，无第三方运行依赖。

```sh
python3 server.py --port 8879
```

浏览器打开 http://127.0.0.1:8879/ 。macOS 也可双击 `启动标注工作台.command`。关闭终端会停止服务。

## 标注操作

- 点击矩形或右侧序号选择标注；修改文字、四个坐标后点击“应用修改”。
- 拖动矩形移动，拖动四角调整大小。选择“补框 B”拖出新框，默认文字为 `□`，随后填入实际字符。
- 红色“重”：重复框或同位置标签冲突；紫色“字”：文字录入疑点；橙色“空”：疑似空白框；黄色“叠”：重叠待核。
- 可切换“仅问题框”。确认处理后勾选“此框提示已处理”。提示是复核线索，不代表已认证错误。
- 删除、调整顺序、文字与坐标修改均可撤销/重做。顺序决定 GT 拼接顺序。
- V 选择，B 补框，H 平移，空格临时平移，滚轮缩放。Ctrl/⌘ Z 撤销；Ctrl/⌘ Shift Z 重做；Ctrl/⌘ S 保存标注文件。
- 应用后的修改自动写入 `草稿/`；“保存标注文件”写入 `保存结果/`。切换图片前会等待草稿保存；多窗口冲突会拒绝覆盖。

## 保存与导出

“导出标注”可下载当前、已复核、有草稿或全部图片的 ZIP，也可下载当前图片的 LabelMe JSON / Pascal VOC XML。

- `annotations-json/`：LabelMe 矩形格式，原图 0 起始像素边界，保留浮点精度；ZIP 中 `imagePath` 指向 `../intact-img`。单个 JSON 下载内嵌图片。
- `annotations-xml/`：Pascal VOC 整数、1 起始闭区间。xmin/ymin = floor(左/上)+1；xmax/ymax = ceil(右/下)。与 JSON 的坐标口径不同。
- `intact-img/`：原图。
- `coordinate/`：0 起始原图像素边界，每行 xmin,ymin,xmax,ymax。
- `gt-label/`：按当前框顺序连续拼接，无换行；一个框的多字符标签保持在一起。
- `gt-index/`：坐标行与 GT Unicode 码点区间对应关系。

原始图例及标注在 `dist/`，不会被编辑写入。`草稿/`、`保存结果/` 和运行缓存已从 Git 排除。

## 残卷保留讨论

点击顶部“残卷保留讨论”，或打开 http://127.0.0.1:8879/fragments.html 。

本轮逐图浏览现存 179 张图片，补入 66 张现存候选和 4 张历史剔除图。重点残卷不等于应删除：是否保留取决于整页完整性要求。另有 38 张残损可用候选倾向保留，白色补片不作为删除依据。

支持按残损程度或编号筛选，打印当前筛选结果。可切换原图/坐标、放大、记录“建议保留/建议剔除/补标后保留”和备注；支持导出讨论 JSON、打印或通过浏览器保存 PDF。此页面只记录讨论意见，不会自动恢复或删除任何数据。

## 共享

仓库已按用户要求公开。公网版通过 GitHub Pages 发布，打开网页即可查看和编辑，不需要安装 Python。

公网版的标注草稿和讨论意见保存在访问者自己的浏览器 IndexedDB 中，不上传到共享数据库。请下载标注 ZIP 或导出讨论 JSON 交回；换浏览器、换电脑或清除网站数据不会保留这些草稿。它不是多人实时协同服务。

本地 Python 版继续使用项目文件夹中的草稿和保存结果。两种版本使用相同的坐标与 GT 导出规则。

默认只监听本机 127.0.0.1。公网版通过浏览器直接生成标准文件，Python 服务仍仅供本机使用。
